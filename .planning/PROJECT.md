# ML Atlas 辅助教材

ML Atlas 为编程与数学基础较弱的学生提供双语解释、可操作实验、参考代码和可复现 Notebook，作为 AI 课程的补充教材。

## 当前目标

按六个单元组织从入门到传统机器学习的主线：AI 与代码、数据输入、可解释模型、回归案例、分类决策、模型比较与分类案例。深入数学和深度学习保留为专题资源，本轮不增加深度学习课程。

学生可以自由阅读；不提供学习考核、完成判定、诊断报告或进度统计，不自动记录访问、答题或实验行为。实验状态保留在页面内存中，语言偏好可保存。历史学习数据不清空、不迁移。

## 架构与交付

- 保留 Vue 3、TypeScript、Vite、三套课程 schema、Catalog adapters 与懒加载。
- 保留静态 GitHub Pages 部署，不增加账号、教师后台或云端记录。
- 课程正文为章节事实来源；生成目录和展示数据必须通过漂移检查。
- 每项重构单独验证、提交和 PR；通过工程与内容验收后逐单元开放。
