# Phase 28.1 — Security

> Retroactive ASVS L1 / STRIDE review of the completed static gradient-descent course. The original two plans predate the current threat-model block, so this register was reconstructed from the implementation, published assets, tests, and release gates.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Typed lesson content → safe renderer | Local bilingual Markdown/KaTeX copy enters the shared sanitized rendering path. | Static instructional text and formulas; no learner-authored HTML |
| UI controls → pure simulation engine | Sliders, selects, and buttons request deterministic numerical states. | Bounded numeric parameters and fixed enum values |
| Public package → browser | Local CSV, JSON, Notebooks, poster, video, transcripts, and interaction payloads are served under the configured public base. | Public non-sensitive course assets with checked manifests and hashes |
| Course → external references | Three end-of-course reading links open in a new tab. | Public URLs only; no account, token, or learner state |
| Existing progress boundary | Final checkpoint uses the pre-existing Algorithm Progress contract. | Local browser progress only; no upload, account, or cloud synchronization |

---

## Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation | Status |
|-----------|----------|-----------|----------|-------------|------------|--------|
| T-28A-01 | Tampering | Published numerical/media package | high | mitigate | Asset builder and Manim check validate exact inventory, source records, probes, chapter markers, Notebook outputs, manifests, and hashes; focused drift tests pass. | closed |
| T-28A-02 | Tampering / Denial of Service | Numerical controls and pure engine | high | mitigate | Inputs are bounded in the UI; the engine rejects non-finite values, invalid sample sets, negative learning rates, and invalid epochs, and records divergence without unsafe hidden clamping. | closed |
| T-28A-03 | Elevation of Privilege / XSS | Bilingual lesson rendering | high | mitigate | Phase content is typed and local, formulas use the shared `MarkdownMathContent` safe path, and the phase introduces no raw `v-html`, executable script, iframe, `eval`, or learner HTML input. | closed |
| T-28A-04 | Information Disclosure | Dataset, Notebooks, checkpoint and progress | medium | mitigate | The five-row dataset and Bike trace are intentionally public teaching data; no secrets or personal data are included, and the phase adds no upload, remote logging, account, or new storage schema. | closed |
| T-28A-05 | Denial of Service | Animated labs and media lifecycle | medium | mitigate | Labs are lazy, trajectories and controls are bounded, timers stop on unmount, observers disconnect, fetch controllers abort, and reduced-motion/static/numerical fallbacks preserve the lesson without continuous animation. | closed |
| T-28A-06 | Spoofing / Reverse tabnabbing | External references and public paths | medium | mitigate | Runtime assets resolve with `withPublicBase`; the only external references are fixed typed HTTPS URLs and use `target="_blank"` with `rel="noopener noreferrer"`. | closed |

*Status: open · closed · open — below high threshold (non-blocking)*
*Severity: critical > high > medium > low — only open threats at or above `workflow.security_block_on` count toward `threats_open`.*
