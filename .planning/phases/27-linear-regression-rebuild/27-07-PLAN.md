## Trust Boundaries

| Boundary | Description |
|---|---|
| Public summary response → Vue state | Fetch failure or malicious/malformed JSON must not become trusted UI state. |
| Learner controls → pure computation | Unbounded/non-finite values can cause invalid or expensive updates. |
| Chart data → SVG/optional WebGL | Visual lifecycle and labels must remain safe and accessible. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-27-05 | Denial of Service | controls/loading/chart arrays | medium | mitigate | Strict parser, aborts, bounds, finite guards, bounded arrays, and reset. |
| T-27-06 | Elevation of Privilege | rendered result/copy | high | mitigate | Typed text rendering, no raw HTML/iframe, safe localized fallback. |
| T-27-07 | Tampering | runtime asset fetch | medium | mitigate | Registered descriptor plus withPublicBase, response status check, strict parse, abort. |
| T-27-08 | Denial of Service | optional Three.js lifecycle | medium | mitigate | Prefer SVG; otherwise controller lifecycle, full dispose, and static fallback tests. |
