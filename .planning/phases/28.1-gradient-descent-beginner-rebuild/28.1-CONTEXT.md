# Phase 28A Context

## Goal

Rebuild the canonical `gradient-descent` course for beginners as six independent chapter pages. The route, chapter IDs, progress stores, checkpoint identity, and legacy links remain stable.

## Locked teaching sequence

1. `loss-function` — five study-hour samples, predictions, residuals, MSE, and a one-parameter loss curve.
2. `landscape` — the same MSE in `(w,b)` space, with surface, contours, a draggable start, and a one-dimensional slice.
3. `gradient-rule` — row-level gradient contributions, negative-gradient direction, and one exact update.
4. `learning-rate` — slow, stable, oscillating, and divergent trajectories, with raw and standardized inputs.
5. `saddle-local-minima` — tilted ravine, Rosenbrock, saddle, and multi-well landscapes.
6. `noise-and-batch` — true full-batch, mini-batch, and SGD updates, followed by the existing read-only Bike training trace.

Every page follows: question → data/model → hand calculation → formula → NumPy code → executed output → reading hint → misconception → prediction → lab → observation → conclusion.

## Numerical authority

- Shared samples: `x=[1,2,3,4,5]`, `y=[52,59,65,72,78]`.
- Model: `y_hat = w*x + b`; residual: `r = y-y_hat`; loss: `MSE = mean(r^2)`.
- Gradient: `dL/dw = -(2/n) sum(x*r)` and `dL/db = -(2/n) sum(r)`.
- Anchor: `w=6`, `b=47`, predictions `[53,59,65,71,77]`, residuals `[-1,0,0,1,1]`, MSE `0.6`, gradient `(-3.2,-0.4)`.
- With `eta=0.02`, the next state is `(6.064,47.008)` with MSE `0.440192`.
- Least-squares reference: `(6.5,45.7)` with MSE `0.06`.
- Batching uses seed `2801`, mini-batch size `2`, SGD size `1`, and preserves the final one-sample mini-batch.
- Divergence is reported honestly at the last finite state; trajectories are never clamped to hide instability.

## Delivery boundary

- PR 1 publishes the shared dataset, pure TypeScript engine, bilingual executed Notebooks, CSV/JSON interaction package, and a language-neutral Manim animation.
- PR 2 publishes the six paged lessons, six dedicated lazy-loaded labs, routing/fallback work, and browser validation.
- No Pyodide, backend, exercise bank, new UI framework, Momentum, Adam, Hessian, proof-heavy optimization theory, or line search.
- `.planning/config.json` and `docs/gpt_advice.md` in the primary checkout are user-owned and excluded.
