# Phase 28B Context

## Goal

Rebuild the existing `optimizer-comparison` course for beginners through one continuous progression: interpretable two-dimensional terrain, four optimizer state machines, a fixed `2→4→1 tanh` MLP, and a real Banknote Authentication transfer. Preserve the existing six lesson IDs, route identity, checkpoints, Progress stores, and Math Lab entry points.

## Locked teaching sequence

1. `training-loop` — forward, loss, `zero_grad`, backward, optimizer step, and a step ledger.
2. `sgd-batch-noise` — full batch, mini-batch, stochastic updates, iteration, epoch, and direct SGD updates.
3. `momentum-rmsprop` — velocity accumulation and ravine damping, then squared-gradient history and per-parameter effective step sizes.
4. `adam-weight-decay` — first/second moments, time step, bias correction, and explicit Adam/L2/AdamW strategy separation.
5. `learning-rate-schedules` — constant, step decay, and linear warmup plus cosine decay, with `optimizer.step()` before `scheduler.step()`.
6. `curve-diagnosis` — controlled four-optimizer MLP comparison, followed by real Banknote transfer under frozen selection rules.

Every chapter follows: question → intuition → mathematics and state → NumPy code → real output → prediction → animation → interaction → observation → misconception → conclusion.

## Numerical authority

- One pure TypeScript optimizer engine owns SGD, Momentum, RMSProp, Adam, weight-decay strategies, schedules, state traces, finite guards, and deterministic replay.
- Momentum follows PyTorch's first-buffer and dampening semantics; RMSProp uses `sqrt(v) + eps`; Adam exposes raw and corrected moments with `t` incrementing once per parameter update; AdamW decay remains outside moment accumulation.
- The fixed synthetic benchmark uses one circle dataset, one `2→4→1 tanh` network, one initialization, one batch order, and one update budget for all optimizers.
- The Banknote transfer reuses the existing local dataset, fixed split, and train-only standardization. The test partition is evaluated once after configurations are frozen.
- Comparison uses both first-step update-norm matching and predeclared practical settings. The course does not claim a universal winner.

## Media and interaction authority

- Four language-neutral 35–55 second Manim animations cover SGD, Momentum, RMSProp, and Adam at 1920×1080, 30fps.
- Each media package includes MP4, SVG poster, reverse knowledge tree, detailed prompt, source, bilingual transcript, chapter markers, version, and hashes.
- A shared `ChapteredMediaPlayer` owns markers, transcript, failure poster, reduced-motion behavior, and Pages-safe paths across Optimizer, MLP, and Gradient Descent courses.
- Six chapter-specific lazy labs expose at most three main control groups and always provide keyboard, reduced-motion, and text/table fallbacks.
