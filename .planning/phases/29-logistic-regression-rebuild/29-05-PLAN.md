## Trust Boundaries

| Boundary | Description |
|---|---|
| Controls/pointer/keyboard events → scene state | Learner inputs can be invalid, extreme, or repeated rapidly. |
| Validated static asset → SVG/table | Large or malformed arrays could corrupt layout if bounds are ignored. |
| Chapter route → async scene/load result | A stale response could update the wrong chapter after navigation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-29-05-01 | Tampering | lab control inputs | high | mitigate | Parse finite values, enforce typed ranges/steps, restore last-valid state, and test endpoints plus one outside step. |
| T-29-05-02 | Denial of Service | SVG models/playback | medium | mitigate | Bound trace/point/bin lengths, sanitize coordinates, require learner-start playback, stop timers on unmount, and disable continuous motion when requested. |
| T-29-05-03 | Tampering | stale scene loads | medium | mitigate | Abort the previous controller on ID change/unmount and ignore aborted results before assigning ready state. |
| T-29-05-04 | Information Disclosure | final scene asset selection | high | mitigate | Loader/scene types exclude reserved test records and tests fail if Phase 29 components reference the handoff's test section. |
| T-29-05-05 | Spoofing | synthetic versus real provenance | medium | mitigate | Carry explicit `dataKind`/source labels into SVG, table, alt text, and results; prohibit cross-source mutation in pure model tests. |
</threat_model>
