## 本批范围

- 单元 1「AI 与代码入门」：AI 总览、Python 前五章主读，后三章作为可自由查阅的选读与分析示例。
- 单元 2「从数据到模型输入」：先划分与泄漏边界，再数据质量、数值特征和类别特征。
- 上述两单元标为 `pilot`，首页推荐；单元 3—6 保持 `preview`。状态仅改变标签和推荐，不限制任何课程的访问。
- 页面讲解、例题结论、实验和 Notebook 均可直接使用。历史学习记录保持原样，不自动记录阅读或实验行为。

课程顺序和状态维护于 `src/curriculum/reading.ts`；章节来自实际 typed 课程，经 `npm run curriculum:generate` 投影到轻量目录。修改正文后执行 `npm run curriculum:check`，不要手工维护第二份章节清单。

## 已知限制与独立验证

- 本工作区没有匹配的离线 wheel 缓存、源数据及重生成环境，28 项检查按既有条件跳过。部署 CI 检查已冻结的公开产物，离线重生成另运行 `npm run test:offline-notebooks`，该命令将缺失环境视为失败。环境说明见现有 Notebook 生成脚本及对应资源文档。
- 历史 manifest 中的生成器哈希描述冻结产物生成时的代码。普通发布检查核对公开文件哈希，不将后来修改的生成器误当作历史生成器；重生成须在匹配环境中重新验证并一起更新产物与溯源记录。
- 数学资源仍有较大的构建 chunk 警告；首页不加载无关重型实验，后续 provider 整理继续保持懒加载边界。
