# 梯度下降一次更新动画字幕稿

## 0:00 — 数据与模型

我们从五条学习时长和分数数据开始。当前模型是 `ŷ = wx+b`，先固定 `w=6`、`b=47`。这一步只做前向计算：每个学习时长经过同一条直线，得到一个预测分数。

## 0:12 — 预测、残差与损失

蓝色位置是预测，橙色虚线连接真实值。残差按 `真实值−预测值` 定义，所以得到 `[-1,0,0,1,1]`。平方后取平均，当前 MSE 是 `0.6`。

## 0:24 — 一维损失切片

暂时固定截距 `b=47`，只改变斜率 `w`。曲线上的每一点都是一个候选斜率及其 MSE。当前参数还不是最低点；最小二乘参考解位于更低的位置。

## 0:36 — 上坡梯度

梯度收集损失对斜率和截距的敏感度。当前梯度是 `(-3.2,-0.4)`。紫色箭头表示损失增大最快的方向，因此它本身不是下降方向。

## 0:48 — 负梯度方向

更新规则前面的负号把紫色方向反转为绿色方向。负梯度回答“怎样让当前局部损失下降得最快”，但还没有决定具体走多远。

## 1:00 — 学习率缩放

学习率 `0.02` 缩放负梯度，得到参数变化 `(0.064,0.008)`。学习率只改变步长，不改变这一时刻由梯度给出的方向。

## 1:12 — 更新并重新验证

参数更新为 `(6.064,47.008)`。用新参数重新计算全部五条预测，MSE 从 `0.600000` 降到 `0.440192`。这只是一次更新；`0.060000` 是最小二乘参考值，提醒我们仍有继续下降的空间。
