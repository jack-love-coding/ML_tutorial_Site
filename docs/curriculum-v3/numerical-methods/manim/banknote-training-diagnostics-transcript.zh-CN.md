# Banknote 训练轨迹诊断：动画文字稿

> 场景 ID：`banknote-training-diagnostics`
>
> 数值来源：Plan 25-03 发布的 `numerical-methods-batch-4-v1` 训练诊断摘要与完整已接受状态轨迹。
>
> 无动画阅读：本文保留五次运行的完整四步诊断、两组受控比较、最佳验证点、终点语义和最终测试报告；不需要依赖运动、声音或颜色。

## 0–8 秒：先读轨迹，再只改一个变量

当一条训练曲线下降很慢、短暂变好后恶化，或者在某个边界停止时，不要同时修改很多设置。这里使用固定教学链：

1. 描述可见轨迹；
2. 提出一个可能原因；
3. 只改变一个变量；
4. 写出下一次运行应出现的可检查现象。

动画聚焦两组真实 Banknote 运行：固定步长 0.02 与 4.0，以及固定 32 与从 32 开始的 Armijo 回溯。这是详细讲解，不是测验或评分。

现有过拟合、梯度消失和梯度爆炸曲线仍是明确标注的确定性合成支持示例。它们没有被改写成 Banknote 结果，也不被本动画替换。

## 8–18 秒：四步诊断方法

第一步只说“看见什么”，避免先用结论替代观察。第二步把形状联系到数值机制。第三步保持其他条件不变，只改一个变量。第四步提前说明下一条轨迹应怎样变化，以便运行后核对。

最佳验证检查点和终点是两种不同记录：

- 最佳验证点选择应保存的参数；它不证明数学收敛。
- 终点的 `kind` 与 `reason` 说明运行为什么结束。验证耐心是模型选择，最大迭代是安全上限，梯度范数达标是数学收敛。

## 18–32 秒：比较 A——固定 0.02 到固定 4.0

两次运行都使用标准化特征和固定步长法，唯一改变是步长。

### 原运行：`standardized-too-small`

1. **可见轨迹：** 损失安全下降，但到迭代上限时梯度仍然很大。
2. **可能原因：** 固定步长太小。
3. **只改一个变量：** 把固定步长从 0.02 增加到 4.0；标准化特征、固定方法和其他常数保持不变。
4. **预期下一条轨迹：** 在 500 次更新以内达到梯度容差。

原运行共有 501 个已接受状态。最佳验证点和终点都在迭代 500，验证 BCE 为 0.288343568660986。终点为：

- `kind = safety`；
- `reason = max-iterations`；
- `iteration = 500`。

这表示运行碰到安全上限，不表示损失发散，也不表示已经数学收敛。

### 下一运行：`standardized-stable`

步长 4.0 的完整轨迹共有 485 个已接受状态。训练和验证损失逐步稳定，梯度变小。最佳验证点和终点都在迭代 484，验证 BCE 为 0.06825592665802883。终点为：

- `kind = mathematical-convergence`；
- `reason = gradient-norm`；
- `iteration = 484`。

这与预期一致：只增大固定步长后，运行在 500 次更新以内达到锁定的梯度容差。结论只适用于这组锁定数据、目标和常数，不是“更大步长总是更好”。

## 32–46 秒：比较 B——固定 32 到 Armijo

两次运行都使用标准化特征，首个提议步长都是 32。唯一改变是采用规则：固定法直接采用，Armijo 先检查充分下降并允许回溯。

### 原运行：`standardized-too-large`

1. **可见轨迹：** 出现一个很低的短暂验证点，随后验证损失恶化。
2. **可能原因：** 固定步长越过可接受区域。
3. **只改一个变量：** 不再直接采用固定 32，改用从 32 开始的 Armijo 回溯；特征空间和初始步长不变。
4. **预期下一条轨迹：** 第一次先接受 16，并保留数学收敛资格。

固定 32 的最佳验证点在迭代 13，验证 BCE 为 0.05885315617651155。终点却在迭代 73，验证 BCE 已变为 0.08285039867735675，终点为：

- `kind = model-selection`；
- `reason = validation-patience`；
- `iteration = 73`。

较低的短暂验证 BCE 只说明检查点一度更好；验证耐心停止并不证明梯度收敛。按照预先锁定的规则，只有数学收敛的运行才有资格进入最终选择，因此不能把这个短暂低点直接当成最终模型胜者。

### 下一运行：`standardized-armijo`

Armijo 第一次试探 32 后拒绝该候选，回退一次并接受 16。首个已接受状态明确记录：

- `acceptedStepSize = 16`；
- `backtrackCount = 1`；
- `iteration = 1`。

Armijo 轨迹共有 49 个已接受状态。最佳验证点和终点都在迭代 48，验证 BCE 为 0.06824699289297452。终点为：

- `kind = mathematical-convergence`；
- `reason = gradient-norm`；
- `iteration = 48`。

这与预期一致：只改变采用规则后，首个可用步长变成 16，并在锁定容差下达到数学收敛。本比较解释的是这组运行中的步长机制，不是“Armijo 永远优于固定步长”。

## 46–58 秒：最佳验证点与终点不能互换

动画使用三种同时带文字的标记：

- 菱形 `◇`：最佳验证检查点，回答“保存哪组参数”；
- 方形 `■`：原运行的终点；旁边写明安全或模型选择语义；
- 圆形 `●`：受控下一运行的终点；旁边写明数学收敛语义。

颜色只用于辅助。虚线与方形、实线与圆形、菱形以及书面 `kind/reason` 共同保留信息，因此色觉差异、静态海报或 reduced motion 都不会丢失结论。

## 58–65 秒：选中检查点与紧凑测试报告

预先声明的选择规则先要求数学收敛，再在合格运行中比较最佳验证点。最终选中 `standardized-armijo` 的迭代 48 检查点。

固定阈值为 0.5，ROC-AUC 使用概率。手动 NumPy 路径的测试结果为：

- 测试 BCE：0.055110123229490826；
- 准确率：0.9805825242718447；
- ROC-AUC：0.9994279176201373；
- 混淆矩阵 `[[TN,FP],[FN,TP]] = [[110,4],[0,92]]`。

scikit-learn 1.9.0 的终点测试 BCE 是 0.05509807557568522，预测一致率为 1.0。这个库基线只用于终点核对。它报告 17 次 LBFGS 迭代，但不能与手动 Armijo 的 48 个已接受状态逐步比较。

本场景没有阈值调优、PR-AUC、校准分析、完整模型评估或求解器排行榜。

## 65–72 秒：海报帧结论

最终静态画面保留两条完整行动映射：

- **慢：** 固定 0.02 在迭代 500 达到最大迭代安全上限；只把步长改为固定 4.0 后，在迭代 484 以梯度范数收敛。
- **越过：** 固定 32 在迭代 73 因验证耐心停止；只把采用规则改为 Armijo 后，首步接受 16，并在迭代 48 以梯度范数收敛。

最佳验证点仍用菱形独立表示。方形和圆形终点都写出原因。画面同时写明：真实 Banknote 轨迹负责本动画结论，合成过拟合/梯度示例仍是独立支持内容。

## 五次锁定运行的完整四步诊断

动画重点展示四条运行；为了让视频失败和无动画路径完整，以下保留 Plan 25-03 摘要中的全部五条诊断。

### `raw-fixed`

1. **可见轨迹：** 验证损失先改善再恶化，同时参数步长仍然很大。
2. **可能原因：** 原始特征尺度让固定步长的条件变差。
3. **只改一个变量：** 保持步长 4.0，只把特征改为标准化。
4. **预期下一条轨迹：** 下降更平滑并达到数学收敛。

终点：`model-selection / validation-patience / iteration 112`。

### `standardized-too-small`

1. **可见轨迹：** 损失安全下降，但迭代上限时梯度仍然很大。
2. **可能原因：** 固定步长太小。
3. **只改一个变量：** 固定步长从 0.02 增加到 4.0。
4. **预期下一条轨迹：** 500 次更新内达到梯度容差。

终点：`safety / max-iterations / iteration 500`。

### `standardized-stable`

1. **可见轨迹：** 训练和验证损失稳定，梯度变小。
2. **可能原因：** 标准化让固定步长可用。
3. **只改一个变量：** 把固定步长替换为从 32 开始的 Armijo。
4. **预期下一条轨迹：** 拒绝不安全试探，并用更少的已接受更新收敛。

终点：`mathematical-convergence / gradient-norm / iteration 484`。

### `standardized-too-large`

1. **可见轨迹：** 低的短暂验证点之后出现恶化。
2. **可能原因：** 固定步长越过可接受区域。
3. **只改一个变量：** 用 Armijo 回溯代替直接采用 32。
4. **预期下一条轨迹：** 首先接受 16，并保留收敛资格。

终点：`model-selection / validation-patience / iteration 73`。

### `standardized-armijo`

1. **可见轨迹：** 第一次试探被拒绝，随后达到梯度容差。
2. **可能原因：** 充分下降检查自适应出可用步长。
3. **只改一个变量：** 保持方法不变，转而检查选中测试终点。
4. **预期下一条轨迹：** 终点与库基线高度一致。

终点：`mathematical-convergence / gradient-norm / iteration 48`。
