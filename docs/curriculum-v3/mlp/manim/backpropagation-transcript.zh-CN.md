# 反向传播动画中文字幕稿

## 0:00｜前向计算与缓存

输入先经过第一层仿射变换，得到 $z^{(1)}$；tanh 把它变成隐藏响应 $h$。第二层再计算 $z^{(2)}$，经过输出 tanh 得到预测 $\hat y$，最后与目标 $y$ 一起产生损失 $L$。

前向传播不只给出预测，还会保存 $x,z^{(1)},h,z^{(2)},\hat y,y$。反向传播稍后会直接复用这些值，不需要倒着猜测输入，也不需要重复推导整个网络。

## 0:24｜从损失得到输出误差

本章使用 $L=\frac12(\hat y-y)^2$。先对预测求导，得到 $\bar{\hat y}=\hat y-y=0.185893$。预测还经过了 tanh，因此必须再乘局部导数 $1-\hat y^2$，得到输出层误差信号 $\delta^{(2)}=0.122081$。

上游梯度和局部导数承担不同角色。前者表示损失对当前节点输出的敏感度，后者表示这个节点如何把输入变成输出。

## 0:52｜沿单路径应用链式法则

输出误差信号先乘输出权重，得到隐藏值收到的伴随量 $\bar h=0.134290$。再乘隐藏 tanh 的局部导数，得到 $\delta^{(1)}=0.091436$。最后乘输入 $x=1.2$，得到 $\partial L/\partial w^{(1)}=0.109724$。

沿一条路径看，反向传播就是连续乘上局部导数。每个因子都能在前向计算图中找到来源。

## 1:28｜展开网络并累加分支

网络展开为两个输入和两个隐藏单元。输入 $x_1$ 同时参与两个隐藏层仿射运算，所以反向时也会收到两条贡献。$\bar x_1$ 必须等于这两条贡献之和。

路径内使用乘法，分支汇合处使用加法。遗漏任何分支都会得到不完整的梯度。

## 2:00｜Reverse-mode 与 VJP

自动微分在前向阶段把原始操作记录成 tape，并保存反向所需的中间值。因为最终损失是标量，reverse mode 从 $\bar L=1$ 开始，按照逆拓扑顺序访问操作。

每个操作计算一次 vector–Jacobian product：$\bar{\mathbf u}\mathrel{+}=J_f(\mathbf u)^{\mathsf T}\bar{\mathbf v}$。这里的加等号表示同一变量可以从多个下游分支接收梯度。框架的 backward 操作是在自动组织这些局部规则，而不是使用另一套数学。

## 2:28｜参数更新与重新前向

梯度表示损失对参数的局部变化率，但它不是参数更新量。更新还要乘学习率并加上负号：$\Delta\theta=-\eta\nabla_\theta L$。

默认场景中，四个参数按照解析梯度完成一次更新。重新执行前向传播后，损失从 $0.017278$ 变为 $0.013425$。这次下降说明当前步长适合这个局部位置，但不意味着任意学习率或任意一步都会让损失下降。
